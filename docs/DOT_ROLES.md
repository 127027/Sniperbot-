# Fünf neue Cleanroom-Cloud-Dots

Der Cleanroom nutzt fünf eigenständige GPT-Rollen, die unabhängig von Endgeräten auf dem separaten GitHub-Branch arbeiten. Ausführliches Protokoll: [DOT_PIPELINE.md](DOT_PIPELINE.md).

1. **Tempo:** Datenbeobachtung und Anpassung der vollständigen GPT-Review-Zahl 4/8/12/24, ohne Marktstille bei Datenausfall zu unterstellen.
2. **Discovery:** Neue, vorhandene und reaktivierte Memecoin-Pools auf mehreren Chains finden und eindeutig protokollieren.
3. **Risk:** Quellen, Liquidität, technische Risiken, Pool-Identität und Datenlücken dokumentieren.
4. **Strategy / Publisher:** OPEN-POSITIONS zuerst, dann Kandidaten; BUY/WATCH/HOLD/SELL/NO_TRADE. Gültige BUY/SELL selbst sofort als immutable GitHub-Order + SHA-Index-Pointer veröffentlichen.
5. **QA / Delivery:** Quittungen pro Client prüfen, Blocker erklären, verwaiste valide Index-Pointer ggf. reparieren, Tagesaudit ergänzen.

Keine Übernahme alter Bot-/Dot-Automationen. Keine echten Trades; lokal nur Papier-Simulation.
