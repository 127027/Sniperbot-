# Sechs eigenständige Cleanroom-Cloud-Dots

Die fünf stündlichen Kernrollen laufen unabhängig von Endgeräten. Zusätzlich führt **Dot 6 täglich** die retrospektive >100%-Gewinner-/Missed-Opportunity- und Systemverbesserungsprüfung durch. Detaillierte Vorgaben: [DOT_PIPELINE.md](DOT_PIPELINE.md) und [DOT6_DAILY_IMPROVEMENT.md](DOT6_DAILY_IMPROVEMENT.md).

1. **Tempo:** Marktaktivität messen, 4/8/12/24 vollständige GPT-Reviews adaptiv steuern.
2. **Discovery:** Neue, bestehende und reaktivierte Pools auf mehreren Chains dokumentieren.
3. **Risk:** Poolidentität, Preis-, Liquiditäts-/Sicherheitsbelege und Datenlücken prüfen.
4. **Strategy / Publisher:** Eigenständig BUY/WATCH/HOLD/SELL/NO_TRADE entscheiden; zulässige BUY/SELL-Signale sofort über GitHub veröffentlichen.
5. **QA / Delivery:** Stundenweise SHA-Pointer, Orders und je Client Receipts prüfen.
6. **Daily Improvement Auditor:** Rückblickend alle aus zugänglichen Quellen belegbaren >100%-24h-Memecoins suchen, für jeden den tatsächlichen Dot- und Paper-Signalweg abgleichen, Fehlentscheidungen und Lücken begründen, Verbesserungen priorisieren und deren Wirkung über Folgetage testen.

Dot 6 darf keine spekulative Order erzeugen oder Schutzprüfungen umgehen. Keine Wiederverwendung alter Bot-Dateien und keine echte Blockchain-Transaktion.
