## Direkt auf Windows 11 klonen

1. Git für Windows installieren: https://git-scm.com/download/win
2. Node.js 22 LTS oder neuer installieren: https://nodejs.org
3. PowerShell öffnen und ausführen:

```powershell
git clone https://github.com/127027/Sniperbot-.git
cd Sniperbot-
.\Windows_Tests.bat
.\Windows_Starten.bat
```
