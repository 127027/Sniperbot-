# Overnight PAPER learning policy — 2026-11-26
Purpose: independently discover and evaluate memecoins, aiming for ten distinct justified hypothetical EUR 50 purchases, and learn from outcomes. This is research only, not an executable trading instruction. No live orders, wallets, secrets, signal pointers, budget/risk relaxation or forced BUYs.
## Cycle
1. Read the latest actual independent worker run metadata and GitHub output, not just tool definitions or self-reported counts. Preserve evidence and distinguish unattempted work from failed tool calls.
2. Compare completed decisions, source freshness, coverage, persistence, and discovery with previous runs. Assign each gap a concrete next action, owner and acceptance test. If cause unknown, test a falsifiable hypothesis rather than claim a timeout or repeat arbitrary prompt edits.
3. Make at most one scoped evidence-driven repair per supervisory iteration. For code changes use an isolated research branch, tests and readback; never deploy untested changes or touch real execution. Preserve prior versions. If blocked, record exact error and actionable next step.
4. Next scheduled independent researcher uses prior lessons, not manual candidate choices. Retain source time and exact chain/contract; read/write/readback; use alternative sources. Persist checkpoint and final decision separately. Support researcher contributes independently sourced evidence only.
5. Persist learning journal with actual run IDs, observations, hypothesis, patch/commit and test result, remaining gap, next experiment. Carry lessons into future scans; avoid retrying identical failed fixes without new evidence.
## Quality and delayed evaluation
- A preliminary checkpoint is not a completed assessment; WATCH/REJECT/DATA_GAP are not BUYs. 10 BUYs is a target, never a quota overriding evidence. Ten distinct qualifying hypothetical entries only, EUR 50 each, no duplicate position counted twice.
- Lock each decision at original time with price source, provider timestamp, exit rule, risk and cost assumptions; never revise past decision using future data.
- At each later review, evaluate matured cohorts (at least 24h since original decision) using actual time-aligned exit/mark evidence and defensible documented costs; report net paper PnL, missing costs/data, drawdown and execution uncertainty. If unavailable, mark pending or unverified, not zero. Compare rejected opportunities and winners retrospectively only as training evidence, separate from decision-time inputs. Positive net PnL in one cohort is not proof of repeatable performance; use independent later cohorts and holdout tests. Do not claim tonight's trades have a verified 24h outcome before tomorrow evening.
- After 10 justified BUYs continue auditing quality and outcomes, no unnecessary changes merely to force profit. No guarantee of positive return.
