# Android Paper 0.1
Installierbare Test-APK, min Android 8 (API 26), empfohlen aktuelles Android System WebView. Kein Play-Store-Release, keine echte Zahlungsfunktion. GitHub Actions Workflow R31 Android Paper APK -> Artifact R31-Paper-Android herunterladen (GitHub-Anmeldung ggf. nötig), ZIP entpacken, APK installieren. Nur diese selbst geprüfte Test-APK verwenden, Installation aus dieser Quelle ggf. kurz erlauben. APK ist pro Build mit temporärem Testschlüssel signiert: Updates erfordern später eigenen dauerhaften Signaturschlüssel; Neuinstallation nach Deinstallation löscht lokales Konto. Keine Schlüssel aus CI exportieren.
App öffnet eigenes leeres lokales Paper-Konto. Virtuelles Geld einzahlen, Investitionslimit und Einsatz einstellen, neue Käufe erlauben. Signalabruf beim Öffnen, Fortsetzen und alle 3 Minuten im Vordergrund; bei geschlossenem Bildschirm/App keine garantierte Ausführung. Keine alten Käufe nachholen, nur frische Signale. Keine Serverkonten, kein GitHub-Schreibtoken, keine Übermittlung von Guthaben. GitHub-Raw-Feed ist öffentlich und per Git-Blob-Prüfung gegen den Pointer gebunden; keine unabhängige Signatur, nicht für Echtgeld. Gerätedaten in privatem Android AtomicFile, keine Android-Backups; Deinstallation löscht sie. Physischer Gerätetest und Dauerbetrieb noch nicht belegt. PayPal-/Echtgeldadapter und Android-Foreground-Service separat erforderlich.
