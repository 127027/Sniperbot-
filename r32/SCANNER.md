# Local discovery pilot
Run node r32/scanner.mjs --once for one real read-only scan; omit --once for repeated scans with 60-second delay after each completed cycle. Writes universe.json under R32_DATA_DIR or the existing R32 local data directory. Do not run multiple scanner processes against the same data directory. Existing server is unchanged. No trades, no signals, no risk clearance.
Sources: GeckoTerminal Solana new pools pages 1/2 and trending page 1, DEX Screener latest profiles and boosts. Sources and original first_seen retained; 24h since last observed, capped at 2000 active identities. This is not a full-market census or proven meme classification. DEX Screener documented tokens/v1 batches up to 30 addresses; two batches per scan, oldest attempt first. 429 triggers per-host backoff. Last successful data retained but stale on error or age >5 min. Fixture tests distinguish pool and token identity, preserve missing liquidity, and never grant PASS. No live probe or Windows acceptance asserted.
