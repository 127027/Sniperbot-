SNIPERBOT R29 - CHATGPT ↔ GITHUB ↔ WINDOWS (PAPER ONLY)
========================================================

ZIEL: Keine kostenpflichtige OpenAI-API auf dem PC.
ChatGPT schreibt nach Freigabe einen isolierten Testauftrag auf GitHub.
Der Windows-Kurier holt ihn regelmaessig ab und meldet das Ergebnis dorthin zurueck.
Ein echter stuendlicher ChatGPT-Job wird erst NACH dem Verbindungstest aktiviert.

1. Alte Sniperbot-Konsole mit Q stoppen.
2. GitHub-Branch "codex/r29-chatgpt-github-paper-cycle-20261115"
   auswaehlen, "Code -> Download ZIP", in NEUEN Ordner entpacken.
3. Windows benoetigt Node.js 22 LTS (https://nodejs.org/).
4. Sniperbot_Starten.bat doppelklicken.
5. Beim ersten Start wird ein GitHub-PAT optional verdeckt abgefragt.
   PAT kostenfrei hier erstellen: https://github.com/settings/personal-access-tokens/new
   Fine-grained, Owner 127027, NUR Repo "Sniperbot-",
   Repository permissions Contents = Read and write.
   Bitte den Token NIE hier im Chat oder in Dateien hochladen.
   GitHub-PAT wird nur auf deinem PC Windows-DPAPI-verschluesselt gespeichert.
   Wenn du noch keinen PAT hast, ENTER: Paper-Bot startet ohne GitHub-Kurier.
6. Dashboard: http://127.0.0.1:3030
   Dort steht der Bereich "R29 - ChatGPT ueber GitHub".
7. Bei erfolgreichem PAT: Dieser Link erhaelt ein neues Windows-Heartbeat:
   https://github.com/127027/Sniperbot-/blob/codex/r29-chatgpt-github-paper-cycle-20261115/research/r29/channel/windows-status.json
8. Dann dem ChatGPT in DIESEM Chat melden, dass der R29-Bot gestartet wurde.
   Wir schicken einen Test-BUY (50 TEST-USDC) und danach einen Test-SELL.
   Diese Tests laufen in einer separaten synthetischen Sandbox, NICHT in deinem
   bisherigen Paper-Konto und NIEMALS mit Echtgeld.

Bereits bestanden: ChatGPT -> GitHub -> CI-Test-Bot -> GitHub -> ChatGPT,
virtueller BUY + SELL, synthetischer Gewinn +28.408 TEST-USDC.
Dies ist KEIN Beweis fuer einen echten Kursgewinn oder Windows-Verbindung.
Synthetische feste Preise 0.05 / 0.08. Auch der CI-Bot ist nicht dein Laptop!

Dein lokales Paperkonto unter %LOCALAPPDATA%\MemeSniperPaper
und deine Wallet bitte NICHT loeschen. R29 benutzt eigenen Unterordner:
%LOCALAPPDATA%\MemeSniperPaper\r29-isolated-sandbox

Die originale OpenAI-API-Anbindung wurde im R29-Startweg AUS gelassen.
Kein API-Key oder aufgeladenes OpenAI-Guthaben erforderlich.
GitHub- und ChatGPT-Nutzungsgrenzen und eventuell erforderliche Genehmigungen
fuer kuenftige unbeaufsichtigte stündliche GitHub-Schreibaktionen bleiben zu pruefen.
