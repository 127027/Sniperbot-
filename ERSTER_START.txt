MEME SNIPER AI V0.4 - STARTANLEITUNG (PAPER ONLY)
===================================

1. Installiere Node.js (LTS) von https://nodejs.org
2. Entpacke die ZIP-Datei in einen Ordner, z.B. C:\MemeSniperAI
3. Doppelklick auf Sniperbot_Starten.bat (einziger regulärer Starter)
4. Falls der Browser nicht automatisch oeffnet: http://127.0.0.1:3030
5. Beim ersten Start den GitHub-Token verdeckt im Fenster eingeben. Er wird per Windows-DPAPI verschluesselt gespeichert.
6. Im Dashboard Bot bei Bedarf einschalten; nur Testguthaben und simulierte Positionen.
7. Optional ein Demo-Testsignal erzeugen; keine echten Trades.
8. Optional Testkauf aus virtuellem Guthaben simulieren.
9. Zum geordneten Beenden im zentralen Fenster die Taste Q druecken.

NUR TESTGUTHABEN! NICHTS WIRD ECHT EINGEZAHLT ODER GEKAUFT.

Fuer GitHub / Codex:
- Installiere Git https://git-scm.com/download/win
- Installiere GitHub CLI https://cli.github.com/
- Doppelklick auf GitHub_Private_Hochladen.bat.
- Anmelden, privaten Namen waehlen, GitHub-Upload bestaetigen.
- Gib Codex danach den Link des neuen Repositories und AGENTS.md.

Paper-Konto und Einstellungen liegen unter %LOCALAPPDATA%\MemeSniperPaper.
Markthistorie liegt im bestehenden Projektordner .local\research-market.
Beim Aktualisieren diese beiden Speicherorte sichern und nicht ueberschreiben.
Alle lokalen Komponenten laufen nur bei geoeffnetem zentralem Fenster.
Windows darf nicht in den Energiesparmodus wechseln.
