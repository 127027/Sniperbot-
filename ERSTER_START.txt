MEME SNIPER AI V0.3 - STARTANLEITUNG
===================================

1. Installiere Node.js (LTS) von https://nodejs.org
2. Entpacke die ZIP-Datei in einen Ordner, z.B. C:\MemeSniperAI
3. Doppelklick auf Windows_Starten.bat
4. Falls der Browser nicht automatisch oeffnet: http://127.0.0.1:3030
5. Klicke 'Test + EUR' mit 50 Euro.
6. Klicke 'Bot AUS - Einschalten'.
7. Klicke 'Testsignal erstellen'.
8. Klicke 'Testkauf 50 USDC'.
9. Der Test-Coin liegt in 'Gekaufte Coins' im HOLD-Modus.

NUR TESTGUTHABEN! NICHTS WIRD ECHT EINGEZAHLT ODER GEKAUFT.

Fuer GitHub / Codex:
- Installiere Git https://git-scm.com/download/win
- Installiere GitHub CLI https://cli.github.com/
- Doppelklick auf GitHub_Private_Hochladen.bat.
- Anmelden, privaten Namen waehlen, GitHub-Upload bestaetigen.
- Gib Codex danach den Link des neuen Repositories und AGENTS.md.

Alle Daten liegen lokal in .local/. Der Bot laeuft nur solange der
Windows-Prozess aktiv ist und der Laptop nicht schlaeft.
